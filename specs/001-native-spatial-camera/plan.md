# Implementation Plan: Native Spatial Camera

**Branch**: `v3/001-native-spatial-camera` (on approval) | **Date**: 2026-10-10 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `specs/001-native-spatial-camera/spec.md`
**Master plan**: `docs/v3/HYPRVX_V3_MASTER_PLAN.md` (§C blueprint, §F tests, §I Sprint 1)

## Summary
Rebuild a clean, narrow Hyprland v0.56.2 patch series that implements a camera view transform for the window
pass. The transform must be correct in pixels (fix RC1 surface clip, RC2 pass simplification, culling, damage)
and in input (inverse hit-test, surface-local coordinates, drag). It is driven by a dev-only control, verified
by pixel captures and virtual-pointer logs in an identity-checked nested session. It ends with a plugin-hook
spike that decides the production delivery mechanism.

## Technical Context
**Language/Version**: C++23 (Hyprland patch, plugin), C++20 (`hyprvx_core`), Bash (scripts), Python 3 `-I` (analysis)
**Primary Dependencies**: Hyprland `efb50993…` + host aquamarine 0.15.1 / hyprutils 0.14.2 / hyprlang 0.6.8 /
hyprgraphics 0.5.1 / hyprcursor 0.1.13; hyprwayland-scanner v0.4.6 (built locally); wayland-client; GTest
**Storage**: N/A (state persistence comes in later features)
**Testing**: GTest (L2); nested harness + `grim` + analyzer (L4/L5); virtual pointer + test client logs (L5b)
**Target Platform**: CachyOS, AMD iGPU, nested Hyprland (Wayland backend) inside the host session
**Project Type**: compositor patch series + C++ libraries + dev tools
**Performance Goals**: Identity camera adds no pass elements (Constitution III). Drift frame cost is measured,
not optimized, in this feature (`noSimplify` is accepted).
**Constraints**: Build `-j4`, `MemoryMax=6G` (≈2.8 GiB free at audit). No host interaction. No uinput.
**Scale/Scope**: 1–3 test windows, 1 output (scale 1 and 1.25)

## Phases (within this feature)
1. **Phase 0, evidence & recovery**
   - Fresh V1 core configure in `build-v3/` → GTest L2. CMake options `HYPRVX_WITH_SDL`,
     `HYPRVX_WITH_WAYLAND_PLATFORM` and `HYPRVX_WITH_HYPRLAND_PLUGIN` gate the matching targets and their
     dependency discovery. Protocol XML paths come from `pkg_get_variable(wayland-protocols pkgdatadir)`.
     A headless configure (all three OFF) needs only a C++ toolchain, GTest, nlohmann_json and Python 3.
   - Fetch-and-pin scripts; build stock-from-source and V2-as-is.
   - Capture V2 artifacts to confirm U1 (RC1/RC2) visually.
2. **Phase 1, render proof**
   - Patches: 0001 CameraMath + monitor camera state; 0002 render seam (compose hint, transformed clip,
     `noSimplify`, dim outside, scanout block); 0003 culling; 0004 damage; 0005 dev control.
   - Tests: T-ID, T-Z*, T-PAN, T-STALE, T-STALE-STATIC, T-OFF (`contracts/test-tooling.md`).
   - Gates before any patch is judged: GATE-A (stock vs stock ×3 pixel-identical) and GATE-N (the analyzer
     reliably detects the U1 artifacts in V2-as-is; decision rules S1/S2/P/N/H in `contracts/test-tooling.md` §6.1).
3. **Phase 2, input proof + delivery spike**
   - Patches: 0006 hit-test (`windowAt` monitor by screen pos, `windowSurfaceAt`, `surfaceLocalAt`); 0007
     seat-local paths (fallback local, held-button, constraints, warps); 0008 decoration/corner hit selection
     through the inverse transform, and blocking + logging of compositor move/resize drags while the camera is
     non-identity (FR-012; moving windows via `O(w)` is Feature 002); 0009 popup reposition/onMap safety.
   - Tests: L5b.
   - Spike: reproduce 0002–0009 with `createFunctionHook` in a plugin on a stock-from-source build; run the
     same suite; write `delivery-decision.md`.

## Risks
| Risk | Mitigation |
|---|---|
| Hidden seams beyond the 10 mapped | Stop condition; record each new seam with file:line before adding |
| Nested screencopy differs from real output | Geometric criteria only; physical checks in later phases |
| RAM pressure during builds | `-j4`, `MemoryMax`, ccache; one heavy job at a time (`contracts/test-tooling.md` lock); stop on swap thrash |
| Author and verifier are the same agent (DV3-15) | Tests written from the spec before patches are judged; GATE-A/GATE-N; R1 as a clean-room rebuild and source-verification report (T044); test changes after patches exist need a reason in `integration-log.md` |
| Fractional scale rounding | Run tests at scale 1 and 1.25; tolerance ± 2 px |

## Complexity Tracking
| Exception | Why needed | Simpler alternative rejected because |
|---|---|---|
| `noSimplify` while camera ≠ identity (perf cost) | Removes RC2 without touching every pass element | Camera-aware bbox/opaque regions add seams before correctness is proven; scheduled for Phase 7 |
